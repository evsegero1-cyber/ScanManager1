# ScanManager 2.0

Каталог товаров склада со штрихкодами, маршруты подпитки с напоминаниями, профили сборщиков с уровнями и достижениями, админ-панель.

Kotlin, Jetpack Compose, Material 3, Firebase (Auth и Firestore), WorkManager.

## Как получить APK
Каждый пуш в `main` собирается в GitHub Actions. Готовый APK появляется во вкладке **Releases**,
его можно скачать прямо с телефона. Ещё одна копия лежит в артефактах сборки.

> Первую установку делайте **после удаления старой версии**: у новой другая подпись.
> Следующие версии ставятся поверх. Ключ подписи лежит в `keystore/`, не удаляйте его.

## ⚠️ Обязательно: правила Firestore
Файл `firebase/firestore.rules` нужно вставить в консоль Firebase:
**Firestore Database → Rules → вставить → Publish**.
Без этого любой пользователь может сделать себя админом.

После публикации правил:
- изменить роль, опыт и уровень может только админ;
- авто-достижения (id 13/14/15/16) выдаются только при выполнении условий;
- каталог, маршруты и список достижений меняет только админ;
- старое приложение у обычных пользователей не сможет начислять опыт, поэтому всем нужно обновиться.

## Что исправлено по сравнению со старой версией
- Опыт не накапливался: при выдаче достижения он обнулялся из-за перевёрнутой проверки на null.
- Роль ADMIN проверялась только в приложении, база её не защищала.
- Удаление маршрута оставляло его товары в базе.
- При переименовании бренда, категории или подкатегории в товарах оставались старые названия.
- Можно было удалить категорию с брендами внутри, и в базе оставались «сироты».
- Напоминание могло поставиться дважды на один товар. Теперь у каждого товара одно напоминание, и оно снимается при отметке «выполнено».
- Фото хранились в самом товаре, из-за этого список грузился медленно. Теперь фото лежат в `product_images`,
  а в админке есть кнопка переноса старых фото (иконка 🔧 на экране «Категории»).
- Регистрация могла создать аккаунт без профиля.
- Убраны лишние разрешения, пустые экраны и тестовая кнопка; APK стал release-сборкой с R8.

## Тесты
